# Design Context

Korean-learning app (动物城 / Animal City). Confirmed with the creator:

## Target audience
青少年 / 学生 (teens & students) learning Korean. Playful and energetic, but the
visuals should feel warm and personal — not childish, not corporate.

## Use cases
兴趣驱动的沉浸体验 (interest-driven, immersive). Users come because they enjoy
K-culture and the Animal City world/characters, not to grind a curriculum.
Atmosphere and emotional connection matter more than information density. The
主线 (main line) is 兔莉日记 — a daily story-diary. Supporting: 40音 phonetics,
grammar, graded reading, listen/speak/read/write practice, plaza (social feed),
radio (podcasts).

## Brand personality / tone
治愈手账 · 温暖手绘 (healing scrapbook · warm hand-drawn).
- Warm paper backgrounds (oklch ~96-97% L, hue ~50-60, low chroma), never pure white.
- Hand-written display accents: **Caveat** (script) + **Fraunces** (serif display).
- Hand-drawn illustrations (the house/place PNGs in /public/images/map) are a
  core asset — keep and feature them, don't strip them for clean lists.
- Soft rounded corners, gentle drop shadows, dashed hand-drawn connector lines.
- Motion: gentle ease-out (quint/quart), no bounce. Respect prefers-reduced-motion.
- Per-step accent colors via oklch, tinted neutrals toward warm hue.

## Hard constraints learned on the map/learning-path page
- Never let connector lines/curves cross over text. Curve lives in its own left
  lane; text lives in right-side cards.
- Learning order is fixed: 40音 → 兔莉日记(主线) → 语法 → 分级阅读 → 听说读写练习
  → 动物城广场 → 动物城电台.
- Single title only (no duplicated kicker + title).
- Pages must be practical (tell the user what to do & when), not decorative.
- i18n: strings live in src/locales/zh.ts + en.ts, keyed `map.*`. Fetch via t(key, lang).
- Desktop daily uses a separate component (src/components/desktop/DesktopDailyPage.tsx);
  entries added to mobile daily must also be added there.
