# Blog：韩文按钮改中文 + 返回主页按钮

## 需求（已和用户确认，简化版）
1. **韩文 UI 改中文**：把 blog 界面里写死的韩文按钮/标签/提示直接改成中文。**不做语言切换开关**。
2. **返回主页按钮**：blog 顶栏加个房子图标 → 主页 `/`（原 `←` 回上一级/日记页保留）。

## 不动的部分（重要）
- NPC 名字、帖子正文、评论内容、韩语例句 —— 这些是**学习内容**，必须保留韩文。
- 品牌名（토리네 동물 도시）可保留韩文氛围，或按用户后续意见。
- 分类 tab 的 `key`（'서울 일기'等）是数据库字段值**不能改**，只改显示文字 label。

## 要改的韩文 UI（直接替换成中文）
逐文件扫描替换（约 60 处），主要在：
- BlogListClient.tsx：홈/피드/알림/북마크/내 프로필/팔로잉/인기글/전체/저장한 글/보기 等；LEVEL_TITLES 等级头衔(34行)；CATEGORY label(59-63)；空状态文案。
- BlogReaderClient.tsx：팔로우/댓글/좋아요/저장 等。
- BlogComposer.tsx：发帖 UI。
- PostCard.tsx / PostGallery / BlogOnboarding / AuthorProfile：行内标签。

## 做法
直接把韩文字面量改成中文字面量（不引入 i18n key、不搞双语）。分类 label 用中文、key 不动。

## 返回主页
- 移动端顶栏 `←` 旁加房子图标 `onClick={()=>router.push('/')}`。
- 桌面端左栏 `.blog-nav` 顶部加「首页」入口（桌面 topbar 被隐藏，桌面用户现在没返回入口）。

## 验证
tsc + build + Playwright 实测 blog 界面全中文、返回键跳主页、分类筛选仍正常。
