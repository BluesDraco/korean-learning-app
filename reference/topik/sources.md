## Question Format Reference
### TOPIK I (초급, 1-2급)
- Listening: 30 questions, response/place/topic/what-next types
- Reading: 40 questions, vocabulary/grammar/understanding/summary types

### TOPIK II (중고급, 3-6급)
- Listening: 50 questions, short dialogue/long dialogue/lecture types
- Reading: 50 questions, fill-blank/main-idea/order/inference/attitude types

## Key Exam Characteristics
- Multiple choice with 4 options
- Distractors that "sound plausible but are wrong"
- Difficulty progresses within each section
- Real-life scenarios dominate (daily life, work, school, public services)
- No culture-specific knowledge required (test measures language ability only)
