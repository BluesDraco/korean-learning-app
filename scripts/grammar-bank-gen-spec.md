# 语法练习离线题库 · 生成规范（gen-grammar-bank 与 QA 共用）

你在为一个韩语学习 App 的**语法课**批量出**产出型练习题**。四类题：听力、听写、仿写、续写。这是从零创作的原创题，**每一句韩语都必须是你新造的**，绝对不允许照抄本课卡片自带的例句（cardExamples / scenarios / structures 里的韩语）——脚本会把这些句子作为「禁用句」列表传给你，你造的句子不得与它们雷同（换主语、换宾语、换场景）。

**为什么强制原创**：听力/听写如果用学习者已经在课文里见过的句子，就变成"背答案"，失去练习意义。这是本次改版的核心目的。

## 输入（脚本按课提供）

- `grammarPoint`：目标语法点（= card.title，如 `-고 있다, -고 있었다`）
- `whatItDoes` / `whatItDoesBody` / `structureNote`：该语法点的功能与用法说明
- `blocklist`：本课已有韩语句（禁止雷同）

## 输出格式（每类型一个 JSON 数组）

### 听力（listening）
```jsonc
[{ "ko": "지금 음악을 듣고 있어요", "ans": "现在正在听音乐。",
   "options": ["现在正在听音乐。", "昨天买了衣服。", "想去济州岛。", "在图书馆看书。"] }]
```

### 听写（dictation）
```jsonc
[{ "ko": "동생이 자고 있어요", "zh": "弟弟正在睡觉。" }]
```

### 仿写（imitate）
```jsonc
[{ "ko": "저는 커피를 마시고 있어요", "zh": "我正在喝咖啡。",
   "swapSlot": "把宾语『커피』换成别的你在喝或吃的东西", "swapRole": "object" }]
```

### 续写（continue）
```jsonc
[{ "ko": "지금 뭐 하고 있어요?", "zh": "你现在在做什么？",
   "expectHint": "用『-고 있다』说出你现在正在做的事" }]
```

## 质量硬要求

0. **零抄袭原创**：每句韩语全新创作，不得与 `blocklist` 雷同。场景生活化、多样（购物/交通/天气/学校/职场/医院/餐厅/旅行/爱好/家庭…）。
1. **目标语法强制**（听力/听写/仿写）：每句必须真实、正确地使用 `grammarPoint`。仅仿写的模板句、听力/听写的题干句受此约束；**续写的 opener 不必用目标语法**（目标语法由学习者作答时提供），但 opener 必须能自然引出一句用该语法的回答。
2. **韩语正确**：조사（은/는/이/가/을/를/에/에서…）、时态、敬语阶（以 해요体 为主）、不规则活用、分かち書き（词间空格）全部正确。
3. **听力答案位置均匀**（极重要）：一课 4 道听力题，正确项要轮流落在 4 个位置（不要都放第①个）。QA 会检查分布倾斜。
4. **听力诱答"像样但明确错"**：3 个中文诱答不能与正确项同义，也不能蠢到一眼看穿；错要错得有道理（方向错/信息不符/近义混淆）。四个选项等长感、风格一致。
5. **听写单句**：句子干净、单句、无逗号分句（听写要能整句复现），≤10 词。
6. **仿写换词槽**：`swapSlot` 是**中文**方向提示，明确指出替换哪个成分（如"把地点换成别的场所"）；`swapRole` 从六枚举取一：`subject | object | verb | place | time | plain`。选**真正可替换的实词槽**，别选语法核心（换了就不成句/不用目标语法就错）。替换后句子应仍自然、仍用目标语法。
7. **续写 opener 必须是问句或悬念句**：如 `주말에 뭐 할 거예요?`（问句）或 `요즘 새로운 취미가 생겼어요.`（悬念，自然引出"是什么"）。`expectHint` 是**中文**，指导学习者怎么用目标语法作答。
8. **字段纯度**：`ko` 字段纯韩文（含标点，不得混中文汉字）；`ans` / `options` / `zh` / `swapSlot` / `expectHint` 纯中文（不得混韩文）。QA 会用正则检查。
9. **数量**：每类型每课 4 题（脚本参数 N_PER_TYPE 控制）。

## 自检（生成后，脚本会做，你也自查）

- 每类型题量对、字段齐、JSON 合法。
- 听力恰 4 选项、正确项在选项内、4 项互异、答案位置分散。
- 听写/听力/仿写的 ko 真实使用目标语法（脚本用 grammar-judge 复核，不过则重生成一次、再不过丢弃）。
- 续写 opener 是合法韩语问句/悬念句。
- 所有 ko 不与 blocklist 雷同。
- 字段纯度：韩语字段无中文、中文字段无韩语。
