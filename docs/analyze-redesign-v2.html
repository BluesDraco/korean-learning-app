语法 02

N + 에서 A1 地点助词
在某个地点做动作
에서 接在场所名词后，表示"在～"，说明动作发生的地点。与只表示位置的 에 不同：에서 强调"在这个地方发生了动作"。
01
카페에서 커피를 마셔요.
在咖啡馆喝咖啡。
02
학교에서 한국어를 배워요.
在学校学习韩语。
03
집에서 쉬어요.
在家休息。
V + 아/어서 A2 连接语尾
"先做前一动作，再做后一动作"
表示两个连续动作，前一动作是后一动作的前提或方式。与 -고 不同：-아/어서 强调前后动作紧密连接。
01
친구를 만나서 밥을 먹었어요.
见了朋友，然后一起吃了饭。
02
학교에 가서 공부해요.
去学校学习。

学习建议

今天学的两个语法都是"日常场景连接词"。挑一个咖啡厅或学校的场景，用 -에서 + -아/어서 造 3 个新句子。
