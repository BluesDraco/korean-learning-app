## 总体结论：PASS

## 1. 敬语层级
- Line 121 房东 `안녕하세요. 토리 학생이죠?` — 하세요체 + 「-죠?」确认语气，房东对学生租客的礼貌但轻正式语气，正确。
- Line 128 Tori `네, 안녕하세요. 잘 부탁드려요.` — 해요体 +「부탁드리다」（부탁하다的敬语），面对房东表达敬意，非常得体。
- Line 136 房东 `보증금 500만, 월세 50만, 관리비 5만 따로예요.` — 해요体简明播报，标准。
- Line 143 Tori `관리비에 뭐가 들어 있어요?` — 해요体询问，正确。
- Line 151 房东 `인터넷이랑 수도세만 들어 있어요. 전기세는 따로.` — 해요体首句，末句省略「-예요」为「따로」，口语中确实会这么说，但**房东正式解释费用时更常加「-예요」/「-입니다」**。**轻微**
  - 位置：Line 151
  - 建议：改为「전기세는 따로예요.」保持敬语层完整。
- Line 163 Pick 正解 `수도세, 전기세도 들어 있어요?` — 해요体询问，正确。

## 2. 对话自然度
- 「토리 학생이죠?」— 韩国房东对学生用「이름 + 학생」称呼是真实做法，还原度高。
- 「보증금 500만, 월세 50만, 관리비 5만 따로예요」— 数字缩略"만원"的方式（去掉"원"）是韩国房产/理财口语，正确。
- 「인터넷이랑 수도세만 들어 있어요. 전기세는 따로.」— 中等偏简的房东语气，"~만 들어 있어요" 结构正确。
- 「관리비에 뭐가 들어 있어요?」— 韩国留学生实际租房必问句，教学价值极高且自然。
- Line 149 「인터넷이랑 수도세만 들어 있어요」— **实际韩国 원룸 관리비**通常包含：수도세（水费）、가스공용비（公用煤气）、청소비、엘리베이터 유지비；**很少免费包含인터넷**（互联网需另签合约或额外收费）。**中等**
  - 位置：Line 151-152 opening/dialogue
  - 说明：设定"관리비含网费+水费"不符合韩国原型 원룸 실제 상황（互联网通常需要月付 20000~30000원 单独契约）。作为教学可简化，但学习者到实际场景会被误导。
  - 建议：改为「수도세랑 청소비만 들어 있어요. 전기세랑 인터넷은 따로예요.」更贴近现实。

## 3. 回应词选择
- 「잘 부탁드려요」— 面对房东/前辈/长辈标准客套语，正确。
- 「토리 학생이죠?」— 「-죠?」既是确认也是熟络的问候感。

## 4. 文化元素
- 韩国 부동산 계약 流程：중개사预约 → 房东现场 → 房东出示条件 → 签约。还原度高。
- 「500/50」数字水平 — 학교 근처 원룸 首尔实际水平，合理（同 Day 16 一致）。
- 关리비 5만 — 首尔 원룸 관리비 3~8만 원 区间，合理。
- 房东穿西装戴金链 —— 韩国 임대업 房东典型形象，剧情张力好。
- 「관리비 5만 따로」— 韩国"관리비별도"/"관리비 포함"是找房广告核心信息，教学切入点极佳。
- 「관리비에 뭐가 들어 있어요?」发问 → 房东"愣一下"—— 因为**韩国留学生大部分不会问这个细节**，房东惊讶的心理描写真实。
