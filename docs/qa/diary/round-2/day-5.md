## 1. 敬语层级
- Haru 对 Tori：`안녕! 너 301호 새로 온 학생이지?` → **반말**（`너` / `-지?`）。
- Haru 之后 `나는 하루야. 302호.` → **반말**（`나는` + `-야`）。
- Haru `같이 아침 먹으러 갈래? 식당 어디 있는지 알아?` → **반말**（`-ㄹ래?` / `알아?`）。
- Tori 对 Haru：`네, 맞아요. 저는 토리예요.` → **해요体**。
- **中等问题**：Haru 和 Tori 是初次见面（走廊偶遇），Haru 直接对 Tori 用 반말，但 Tori 对 Haru 用 해요体 — 这个不对称在韩国实际生活中**不合规**。第一次见面的同龄同学，标准做法是：
  - 两人都用 해요체（Haru: `안녕하세요! 301호 새로 온 학생이에요?` / Tori: `네, 맞아요. 저는 토리예요.`）；或
  - 一方主动提议 말 놓자（"我们说反말吧"）后同步转 반말。
- 单方面从上来就用 반말（对同龄不熟）会显得**没礼貌**，即便是仓鼠这种活泼角色，日常也会先问「몇 살이에요?」或先 해요체 一两句再转 반말。
- **Day 7 已经出现同款问题的补救逻辑**：Day 7 Haru 也是对 Tori 반말 (`토리, 괜찮아?`)，但 Day 7 时两人已认识几天，反말可接受。**Day 5 是第一次见面** → Haru 上来就 반말不自然。
- **建议**（不改代码）：将来若可调整，Haru 首两句改 해요体，或 diaryText/剧情说明 Haru "热情自来熟主动 mal 놓자" 的性格设定作为文化解释。

- Tori 内心 `어디서 봤더라… 이 얼굴…` → 반말，合规。

## 3. 回应词选择
- Tori `네, 맞아요.` → `맞아요`（对/没错）在被人确认身份时非常自然，选择极好。
- Pick 正解 `아니요, 몰라요. 같이 가요!` → 语义准确：坦白不知道 + 顺势跟着走。
- 干扰项 `저는 안 먹어요.`（我不吃早饭）→ 拒绝邀请无理由，情境不合适，合理干扰。
- 干扰项 `네, 알아요. 혼자 갈게요.`（我自己去）→ 与"结交朋友"剧情相反，合理干扰。
