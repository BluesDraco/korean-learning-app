## 2. 对话自然度
- 「어디가 불편하세요?」— 韩国药店/内科最标准问诊开场，还原度极高。
- 「감기 걸렸어요. 콧물이 나요.」— 感冒描述"感冒了 + 具体症状"顺序自然。
- 「기침도 해요?」— 补问咳嗽是否，逻辑连贯。但见 §1 建议改为「하세요?」。
- 「식후에 드세요. 따뜻한 물 많이 마셔요.」— opening 出现，「따뜻한 물 많이 마셔요」是韩国药剂师最常见的告别叮嘱，真实。

## 3. 回应词选择
- 「네, 좀 해요」— 「좀」轻程度副词，配合"有点咳嗽"的谦逊表达，自然。
- 「알겠습니다」+「감사합니다」— 面对医护的标准接受语。

## 4. 文化元素
- 药店场景真实：韩国药店确实是"感冒药 + 鼻涕药 + 咳嗽药"分包卖，白色招牌「약」大字，还原度高。
- 「식후에 드세요」— 韩国药剂师标配指令。
- opening Line 46 「감기약, 콧물약, 기침약. 식후에 드세요.」— 但**韩国药店实际发药时一般是复合药（종합감기약 = 综合感冒药），不会分开 콧물약/기침약 三包**。分包更像医院处方后的药袋。这里的三种"分开药盒"设定偏理想化。**轻微**
  - 位置：opening Line 47-48
  - 建议：改为「종합감기약 하나」，或让白鹭姐姐问"콧물이 심해요, 기침이 심해요?"再针对性拿一两种药。
