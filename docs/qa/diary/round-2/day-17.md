## 2. 对话自然度

**中等问题：Line 130「충전도 해 주세요.」**
- 语法上正确，但**韩国地铁站现场充值实际最常用的说法**是「충전해 주세요」/「충전 좀 해 주세요」/「만 원 충전할게요」。加「도」意味着"也帮我充值"，暗含"除了买卡还要充值"—— 语境上勉强通（因为前一步是买卡），但**「充值」和「买卡」通常是同一交易环节**，用「도」略生硬。
- 更自然：「그리고 만 원 충전해 주세요.」或「만 원 충전도 해 주세요.」（数字前置更常用）。
- **中等**
  - 位置：Line 130
  - 建议：改为「그리고 만 원 충전해 주세요.」或「만 원 충전도요.」

**中等问题：Pick 正解「카드로 할게요.」情境不匹配**
- Line 155-156 情境「Tori 要付钱了。她想刷卡支付」
- 但**Tori 刚办完 T-money 卡，还没充值**，此时她要付的是"办卡+充值一共14000원"。如果她刷 T-money 卡付这14000元，逻辑上冲突（新卡余额为0，不可能刷这个卡付这个卡自身的费用）。她要用**其他信用卡/借记卡**付这笔钱。
- 「카드로 할게요」（用卡付）本身可以指任何银行卡，但用户读到"刚办 T-money 卡"的语境会以为是刷 T-money，造成混淆。
- **中等**
  - 位置：Line 158-159
  - 建议：情境改为「Tori 要用信用卡付这14000元」或明确「신용카드로 할게요.」以避免与 T-money 混淆；或改为「현금 있어요.」表现金付款。

**其他自然度：**
- Line 131 「만 원이요」— 「-이요」缩略敬语尾，售票场景很自然。
- Line 138 「모두 14,000원이에요」— 「모두」= 一共，售票员总额播报常用词，正确。

## 3. 回应词选择
- 「하나 주세요」— 「하나」固有数一，配「주세요」，正确。
- 无「저기요」召唤（Tori 直接走到窗口开口），因窗口场景不需要，OK。

## 4. 文化元素
- T-money 卡在地铁站窗口卖 — 韩国地铁站确实有客服窗口（고객센터）卖 T-money 空卡（4000원），也支持充值现金。还原度高。
- 「4,000원 카드 + 10,000원 충전 = 14,000원」— 数字合理，实际 T-money 空卡在便利店/地铁站都是 2500~4000원 一张。
- 「제5층 안내」海报 — Day 20+ 未来伏笔，剧情设计感很好，保留。

## 5. 剧情叙事韩文
- opening 韩语嵌入 2 处：「티머니카드 하나 주세요.」、「제5층 안내」，都自然。
- 「제5층 안내」— 「제○층 안내」是韩国老式楼层导览海报常见格式，正确。
- recap.praise `티머니카드 get! 이제 서울 어디든 갈 수 있어요!` — 韩英混排「get」+ 韩语「이제 서울 어디든 갈 수 있어요!」— 韩国 SNS 上「-get」（겟）是流行用法，语境风格 OK。
