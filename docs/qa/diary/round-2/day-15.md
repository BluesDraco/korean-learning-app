# Day 15 · Round 2 场景审查报告
文件：src/data/diary/days/day-15.ts
审查时间：2026-07-05
审查员：Round 2 Agent (Day 11-20)

## 总体结论：需调整

## 1. 敬语层级
- Line 113 Haru `토리… 이거 다 먹은 거야?` — 反말（-거야?），朋友间自然。
- Line 121 Tori `편의점이 가까워서…` — 해요体 尾巴掉了（省略「-요」），像小声搪塞，自然。但如果按 Day 11+ 剧情 Tori 对 Haru 已经进入 반말/해요体过渡期，此处**保持 해요体没问题，也可以更亲密改成 「편의점이 가까워서…」的反말 「편의점이 가까워서…」（同形）**——现有写法本身就是反말/해요体口语共通式，OK。
- Line 129 Haru `벽이야. 라면 벽.` — 반말（-이야），正确。
- Line 143 Tori `하루야, 요리 가르쳐 줘.` — 「하루야」呼格 + 「가르쳐 줘」반말请求，Day 11+ 已熟悉 Haru，合理。
- Line 151 Haru `좋아. 다음 주부터.` — 반말，正确。
- Line 163 Pick 正解 `라면 그만 먹을래요.` — **敬语层不一致：dialogue 从 Line 143 起进入 반말区**，Tori 对 Haru 说 반말（가르쳐 줘），但 Pick 又切回 「-을래요」해요体。**中等**
  - 位置：Line 163
  - 建议：既然是对 Haru 说，改为「라면 그만 먹을래.」（반말）更一致；或将情境说明改为"Tori 心里下决心（自言自语）"，可以保留 해요体。目前情境模糊。

## 2. 对话自然度
- Line 136 内心 `정신 안정 물자… 이렇게 쌓였네…` — 「-네」感叹形，独白自然。
- Line 143 `하루야, 요리 가르쳐 줘.` — 「가르쳐 줘」标准请求 반말，自然。
- Line 129 `벽이야. 라면 벽.` — 短句幽默感重现 Haru 的直白风格，非常好。
- Line 137 opening `정신 안정 물자` — 韩语中「정신 안정 물자」不是常用固定搭配，更自然的说法是「멘탈 안정 물자」（网络流行语）或「정신 건강 식품」。**轻微**
  - 位置：Line 137 dialogue 内心 + opening
  - 建议：可改为「멘탈 지켜주는 아이템」或保留原意但注明"网络流行式表达"。

## 3. 回应词选择
- 「토리…」— 呼名 + 省略后续，语气拉长的自然。
- 「좋아」— Haru 应允标准反말。
- 「하루야」— 呼格「-야」用于无收音名字，正确。

## 4. 文化元素
- "泡面墙"设定 — 韩国留学生宿舍常见现象，还原度高，笑点自然。
- 「신라면」「진라면」等 Tori 应该在吃，但未提牌子，OK 保留通用性。
- Haru "教做饭" — 韩国朋友间常见互助场景，符合。

## 5. 剧情叙事韩文
- opening 韩语嵌入 1 处「토리… 이거 벽이야. 라면 벽.」，Haru 反말，正确自然。
- recap.praise 韩语「오늘부터 달라질 거야. 토리, 잘 결심했어요!」— **敬语层混乱**：前半 반말「달라질 거야」，后半 존댓말「결심했어요」，同一句混用。**中等**
  - 位置：Line 256
  - 建议：统一 반말「오늘부터 달라질 거야. 토리, 잘 결심했어!」或统一 해요体「오늘부터 달라질 거예요. 토리, 잘 결심했어요!」。或者把 praise 视作叙述者对读者说，那存在但需明确视角。

## 6. Pick 题情境
- Line 158-162 情境 `Tori看着泡面墙，下定决心。她会怎么说？`
- 正解 `라면 그만 먹을래요.`（我不想再吃泡面了）— 见 §1 敬语层不一致问题。若情境是"Tori 对 Haru 说"，反말更合适；若是"Tori 内心决心"，해요体不合独白风格（独白用반말）。
- 干扰项「라면 더 사고 싶어요.」— 语境相反，明显错误。
- 干扰项「편의점에 갈래요.」— 情境错误（Tori 决心是"不吃"，不是"去便利店"）。
- 情境需再明确对话对象。**中等**
  - 位置：Line 160
  - 建议：情境改为「兔莉抬起头，对 Haru 说：」明确对象，然后正解改反말「라면 그만 먹을래.」；或改为「兔莉心里默默想：」保留 을래요 (해요体在自言自语上勉强但比现在清晰)。
