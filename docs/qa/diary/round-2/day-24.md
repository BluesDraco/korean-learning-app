### 建议修正

**line 122** (Minji)：
```diff
- '좋아! 새로 생긴 데 있어. 같이 가요!'
+ '좋아! 새로 생긴 데 있어. 같이 가자!'
```
理由：Minji 前半 `좋아 / 있어` 都是반말，最后`같이 가요` 突然变해요体，同一句话内部层级不一致，不自然。改成 `같이 가자!`（청유형 반말"一起走"）语气一致 + 更自然。

**line 129** (Tori)：
```diff
- '같이 가요! 어디서 만나요?'
+ '같이 가자! 어디서 만나?'
```
理由：Junho 用 `갈래?` 邀请了她，如果 Tori 反말化朋友群，应回반말。opening 里 line 42 Tori 打字发送 `같이 가요!` 本身也是同样问题——但 opening 是叙事文，可以视为"轻微成长弧"处理不改，dialogue 部分建议改。

**line 157** (pick 正解)：
```diff
- '당연하지! 진짜 가요!'
+ '당연하지! 진짜 갈게!'
+ 或 '당연하지! 진짜 가!'
```
理由：`당연하지` 已是반말，后半 `진짜 가요` 해요体，同一句内混用。且 Haru 问的 `올 거지?` 用了반말，Tori 应用반말回。

**其他 pick 干扰项**：
- line 158 `모르겠어요.` — 해요体，与整段反말场景不匹配，建议改 `몰라.`
- line 159 `카페가 뭐예요?` — 同上，建议改 `카페가 뭐야?`
- 但作为干扰项它们已经"语法本身正确"，Round 1 认为可通过，Round 2 建议同步改成반말以保持场景纯洁度
