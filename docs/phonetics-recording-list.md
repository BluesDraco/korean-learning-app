## TTS 兜底范围（不录真人）

以下场景全部走 **Edge-TTS sunhi** 韩语女声，由 `src/lib/tts.ts` 的 `speakWord()` 自动处理：

- **字母详情抽屉的拼字示例**（가방、우유、학교 等约 90 条）
- **连读规则例句**（한국어 / 한구거 等约 82 条 = 41 例 × 写/读）
- **综合拼读 30 词**（네 / 안녕하세요 等）
- **合成器拼出的字**（用户实时拼 → TTS）
- **练习题音频**（出题时 TTS）
- **易混对照卡的对比试听**（同样走核心字母 registry，若不命中 → TTS）

`playPhoneticAudio(text)` 的逻辑：
1. 先查 `audioRegistry` → 命中就播真人 mp3
2. 不命中 → 调 `speakWord(text)` → Edge-TTS sunhi 播
3. mp3 加载失败（404 / decode 错）→ 自动回落 TTS

用户体验上：四十音核心字母听到真人音；其他场景听到 sunhi TTS，无空响。

## 录制约定（如未来要扩充真人录音）

- **声音**：自然口语、女声、清晰
- **速度**：单字慢 0.85 倍，词正常语速
- **格式**：MP3 44.1kHz / 96-128kbps / 单声道
- **静音**：开头 100ms / 末尾 200ms
- **降噪**：背景安静、无明显呼吸气声
- **命名**：与 `audioRegistry.ts` 严格一一对应
- **存放**：`public/audio/phonetics/`，注册后即生效
