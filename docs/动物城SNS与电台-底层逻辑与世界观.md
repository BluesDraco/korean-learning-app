## 0. 一句话定位

在韩语日记(Tori 90 天留学剧本)的世界里，长出的两个「沉浸式陪伴」板块：

- **博客 /blog = 读**：动物朋友们的朋友圈，随日记进度一天天苏醒，用户也能用韩语发帖被 AI 评分。
- **电台 /radio = 听**：动物城的韩语播客，4 档节目 + 实时字幕 + 点词查词。

两者共享同一个世界、同一条时间轴、同一批角色。入口都在日记页(`/diary`)：博客📔、电台📻、贴纸馆🎟️ 三个并列卡片。

## 1. 世界观基石

### 1.1 核心设定
- **用户 = 动物城里唯一新来的那只**。捏一个预制动物形象 + 昵称，作为自己的社媒身份。
- **主角 Tori(토리) 🐰**：中国来的留学生，在首尔(서울)的 **한빛 어학당(韩光语学堂)** 学韩语，先住기숙사(宿舍)后租원룸(单间)。用户是 Tori 的镜像。
- **时间线 = 日记 Day**：剧本共 **90 天**。用户当前 Day = `SELECT MAX(day) FROM user_tori_progress`（默认 Day 1）。
- **世界随学习进度苏醒**：帖子/电台节目按 `unlock_day <= 当前Day` 解锁，一天天出现。

### 1.2 ⭐ 教学第一性 —— 地名用真实名
**最高原则：学习者要"习得"的词必须是真实韩语，绝不能教假词（教假词=喂错=红线）。**

| 场景 | 用什么 | 例 |
|---|---|---|
| 韩语教学正文（要学的词） | **真实名** | 서울(首尔)/한강(汉江)/인천(仁川) |
| 社群品牌风味（不进教学句） | 虚拟名 | 动物城(동물시)、兽尔、卡司昵称 |

- 日记剧本内部用架空地名(수울/수울강/인차공항)是剧本的选择；**博客走教学优先，正文用真实名**。
- 「动物城 = 兽尔 = 你正在学的真实首尔」这层关系，靠**首次进入的引导弹窗**集中解释一次（见 §5.3），正文保持干净的真实名。

### 1.3 内容红线（违反=喂错/出戏）
1. **不超纲**：帖子/节目不能出现比用户当天更难的语法/词汇。
2. **不剧透**：Day N 的内容不能提及 Day > N 的剧情。
3. **守人设**：每个角色固定人格+声音+emoji 习惯，评论/发帖都不能 OOC。
4. **登场日铁律**：角色登场前不能发帖、不能在别人帖里评论。
5. **纯中文释义**：释义/解析/评论中文字段禁止中韩混排。

## 3. 底层数据逻辑

### 3.1 同一条时间轴（最关键的统一原则）
```
日记 Day (user_tori_progress.day)  ← 唯一真相，Day1 = 世界内 9월 1일 일요일
        │
        ├── 博客帖：unlock_day <= 当前Day 才可见
        └── 电台节目：getEpisodesForDay(当前Day) 取当天 4 档
```
两个板块共用 `getUserCurrentDay(userId)` = `SELECT MAX(day) FROM user_tori_progress`（默认 1）。**未登录/新用户默认 Day 1**。

### 3.2 博客 Day 门控 + 等级门控
NPC 帖门控 SQL（`src/lib/server/blog.ts`）：
```sql
WHERE (author_kind = 'npc'  AND unlock_day <= 当前Day)
   OR (author_kind = 'user' AND author_id = 本人)   -- 用户帖只对自己可见
ORDER BY is_featured DESC, published_at DESC
```
等级门控（防喂错）：`초급` Day1-14 / `중급` unlock_day≥15 / `고급` unlock_day≥22。

### 3.3 电台「内容独立 + 发布跟 Day」（2026-07-17 定稿）
- **内容独立**：4 档节目主题不跟日记逐天剧情走，只受电台创作规范(难度/口吻)约束。
- **发布跟 Day**：用户在 Day N 就解锁到电台第 N 期的 4 篇；`day = min(日记进度, maxRadioDay=14)`。
- 库存到 Day14，超出用 `clampRadioDay` 回落展示 Day14。

### 3.4 电台卡混入博客 feed（最近新增）
> 用户要求「把电台放进对应 blog，时间人物不出错」。做法 = **blog 侧读 radioCast，不复制数据**（单一数据源，radio 一改自动跟上）。

- **服务端取数**：`src/lib/server/blogRadio.ts` `getRadioCardsForDay(userId)` = `getUserCurrentDay` + `getEpisodesForDay` → 映射成轻量 DTO `RadioCard`（无字幕/生词）。
  - ⭐ **radioCast.ts 是 301KB，只在服务端 import**，绝不进客户端包。
- **API**：`GET /api/blog/radio`（force-dynamic + private no-store）返回 `{day, cards}`。
- **客户端**：`BlogListClient` fetch → `RadioFeedCard` 组件**每 4 帖插一张**电台卡；只在「전체/🎧듣기」视图混，分类筛选/북마크视图不混；点击跳 `/radio/{id}`。

### 3.5 数据库表
| 表 | 作用 |
|---|---|
| `user_tori_progress` | 用户日记进度(day)，博客/电台门控的时间源 |
| `blog_posts` | 所有帖子(NPC + 用户 UGC)。含 unlock_day/author_kind/level/score_json/ai_status/feature_* 等 |
| `blog_reactions` | 点赞/收藏(每人每帖一行，upsert) |
| `blog_user_stats` | 博客专属用户档案(动物形象/昵称/xp/level/postCount) |

## 5. 功能清单

### 5.1 博客列表页 (/blog)
- **双端布局**：桌面 3 栏(左导航+资料卡 / 中 feed / 右推荐关注+热门标签+收藏+每日 TOP3)；手机仿 Instagram 单列(Stories 行+城镇 Hero+feed)。
- **城镇 Hero**：动物城世界感横幅，显示「N 마리 활동 중」+ DAY 徽章。
- **分类 chips**：전체/일상/소식/서울일기/문화노트/속담/🎧듣기(有音频)。
- **电台卡混入**：当天 4 档节目卡穿插在 feed 里(见 §3.4)。
- **点赞/收藏**：真实持久化(乐观切换+401回滚)。
- **用户档案卡**：等级环 + XP 进度 + 统计 + 连续出勤火苗。
- **发帖入口**：常驻输入条 → 未选形象先引导，已选开发帖弹层。
- **氛围层**：暖色 aurora 背景 + 桌面鼠标柔光。

### 5.2 博客详情页 (/blog/[slug])
- **点词查词**：正文高亮生词，点击展开释义卡 + 🔊 朗读。
- **听力播放器**：波形条 + 进度 + 拖动 seek（音频待接入）。
- **小测验**：可选 quiz，选完显示对错 + 解析。
- **新单词卡**：侧栏列出本文生词 + 🔊。
- **社交**：点赞/收藏/关注(装饰)/分享/评论预览(评论功能"即将开放"占位)。
- **相关推荐**：同分类优先取 3 篇。
- **阅读进度条** + 双击封面点赞爆心动画。

### 5.3 ⭐ 首次引导弹窗 (`BlogWorldIntro.tsx`) —— 最近升级
3 步引导（localStorage flag = `blog_intro_v2_seen`，只弹一次）：
1. **欢迎 + 世界观**：动物城朋友圈、兽尔=真实首尔(서울)、你学的都是真实韩语。
2. **「이렇게 배워요」怎么学**：🔍点词查词+🔊 / 🎧听力 / ✏️小测验 / 📻电台。
3. **「같이 놀면」怎么参与**：🐾选动物发帖被评分 / 🔓随日记 Day 解锁。

带 이전/다음/건너뛰기 + 进度圆点。（旧版只讲世界观，教材感弱，已升级；换 key 让老用户再看一次。）

### 5.4 用户 UGC 发帖（`/api/blog/post`）
1. **一审**：本地关键词 + DeepSeek 语义安全审核(~10s)，blocked 则拦截。
2. **评分**：DeepSeek 多维评分(语法/词汇/表达) + 从安全池选韩语回应。
3. 通过后：帖子入库(只对作者可见)、动物点赞、加 XP。
4. **成长模拟**(`blogGrow.ts`)：用户帖随时间涨赞、动物陆续来评论(质量分决定涨速)。
5. **每日评选**：用户可勾选参赛 → 后台二审入选 → 公开 TOP3 榜单(用改写版正文，不暴露真实账号)。

### 5.5 电台首页 (/radio)
- 双端布局。now-playing 卡(按当前钟点挑最贴近一档) + 编成表(4 档按时段) + 「23명이 함께 듣는 중」社交条 + 连续청취 streak。

### 5.6 电台播放器 (/radio/[id])
- 唱片封面(vinyl 旋转环) + **实时字幕高亮**(随音频 timeupdate) + 点词查词 + 进度/控件/变速/定时关闭 + 本期生词 + 实时聊天(社交装饰) + 同期编成表。
