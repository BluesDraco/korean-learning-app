## P0 Bug (已验证存在)

1. **逐句"读音"按钮在音频未加载时点了没反应** — 刚修复 (改为 SegmentPlayer slow mode)，需验证
2. **IZ*ONE - FIESTA 歌曲无音频** — YouTube 香港区域限制，无法下载。页面会显示"暂无音频"状态
3. **Turbopack 开发服务器内存溢出** — 已改用 `--no-turbo`，但 `npm run dev` 不带参数时仍会用 Turbopack

## P1 Bug (已知但未修)

1. **KoreanKeyboard 缺少滑入动画** — 之前因为 CSS transform 破坏 fixed 定位而移除，需要用非 transform 方案恢复
2. **某些页面的移动端布局可能溢出** — 未做全覆盖测试
3. **暗色模式覆盖不全** — 已修了 10 个文件约 35 处硬编码颜色，但可能还有遗漏
4. **KPOP 页面缓存** — `/korea/kpop/:path*` 设置了 60s 缓存，部署后可能短暂看到旧版本

## 不能上线的问题

1. **没有 CI/CD** — 部署全靠手动 ssh + scp
2. **没有自动化测试** — 零测试用例
3. **没有错误监控** — 前端报错无上报，服务端报错只有 PM2 日志
4. **COS 没有 CORS 配置** — 不能使用 Web Audio API 高级功能
5. **没有速率限制生效验证** — rate-limit.ts 写了但未确认生效
6. **用户数据没有备份机制** — Turso 依赖云服务，本地 SQLite 无备份脚本
