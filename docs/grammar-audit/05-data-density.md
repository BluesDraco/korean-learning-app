## 关键结论

### 密度分层（与 Explore 报告一致）

- **✅ 饱满层（16 部）**：P1-P8, P11-P12, P17-P18, P21-P23 — 全字段达标
- **❌ 精简层（13 部）**：P9, P10, P13-P16, P24-P30 — cardExamples 只 3 条、mistakes 只 3 条
- **⚠️ 边缘（2 部）**：P19, P20 — connectionRules 只 6 条

### 特殊发现

- **P1-P6 综合练习（-l11 6 张卡）specialQuiz 全为 0 题** — 但它们不是走 specialQuiz 路径，而是有 structures/cardExamples/scenarios/mistakes/compareHtml 等，实际是"多题组综合"（`whatItDoesBody` 说明"7 组练习"）。这是**历史设计**，不是缺陷。如果新 UI 走 specialQuiz 唯一路径就要补。
