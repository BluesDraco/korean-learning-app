1产品定位与命名

正式名

토리의 한국어 일기 · Tori 的韩语日记

副标题：30 天和 Tori 一起学韩语

定位三句话

  1. 它不是课程，是 Tori 在首尔留学的 30 天日记，用户每天上线"陪她过一天"
  2. 它不是学习，是养成一只小兔子的语言能力同时也养成自己的
  3. 它不是工具，是 Tori 这个 IP 进入用户日常的入口 — 30 天后 Tori 会成为用户的"韩语朋友"

核心差异

市面上的入门课

大纲驱动 · 系统教学 · 课程进度条 · 严肃干净 · 学完一节继续下一节 · 老师讲你听

Tori 的韩语日记

剧情驱动 · 每天日记 · 故事推进 · 暖手账风 · 今天 Tori 遇到了什么你才会用什么 · 你是同学

关键句：用户不是"在学韩语"，是"今天 Tori 又出了什么糗，我也跟着学一下"。学习是副产品，陪伴才是产品本身。

行业判断

  • 韩语学习市场过去 5 年规模翻 4 倍，主要由 KPOP/韩剧推动
  • 核心用户：18–28 岁女性，喜欢追星/韩剧/韩国文化，付费能力强但抗拒"上课"
  • 市面入门产品同质化严重：40 音 → 你好谢谢 → 我是 XX → TOPIK 词汇
  • 没有人在做"角色养成式入门"。这是空白地

5每日体验设计 — Day Loop

用户每天上线 8–12 分钟，按固定 6 模块顺序走完。每一步都有 Tori 的存在感（短句、表情、台词）。

Day Loop 流程图

  1. 开场（30 秒） · Tori 的日记片段 + 今日心情贴纸 + 10 秒短剧切片
  2. 新词（2 分钟） · 6 个词 + 真人 TTS + 例句卡片
  3. 对话（2 分钟） · Tori 和今天角色的一段对话，听 → 跟读 → 选择正确回应
  4. 语法小卡（90 秒） · 一句话讲清今天的语法，配 Tori 的例子
  5. 输出（2 分钟） · 默写 1 个核心句 / 录音 1 句 / 选场景应用
  6. 复盘（30 秒） · Tori 总结今天："学了 6 个词，明天我们要去便利店！" + 给 1 个"今日贴纸"

每一步的"陪伴元素"

步骤Tori 的存在反馈机制
开场日记体第一人称 + Tori pose—
新词每个词配一张 Tori 的反应表情翻卡有"啪"声 + 微震
对话对话气泡上 Tori 头像选对：💚色 + 叮声；选错：Tori 歪头 + 重读机会
语法Tori 举例 "比如 Tori 想说..."—
输出录音后 Tori 给出反馈表情≥80 分：撒花动效；<80：胡萝卜递过来"再来一次"
复盘Tori 总结，画一张今日贴纸贴纸滑入"今日收藏"
设计原则：每天的 Tori 都不一样。Day 1 紧张兴奋，Day 15 开始疲惫，Day 22 想家哭过，Day 30 笑着告别。这种"角色情绪曲线"让用户和角色有真实的关系。

6六大模块详解

📖

1. 日记开场 (Diary)

第一人称叙事 · 200 字以内 · 配一张 Tori 当天的姿态图 · 偶尔附短剧 10s 切片

⚪️

2. 新词卡 (Words)

6 个核心词 · 真人 TTS · 例句卡片 · 一键加入单词本 · 翻卡动效 + 微震

💬

3. 场景对话 (Dialogue)

Tori 和今天角色的真实对话 · 逐句听 → 跟读 → 选择正确回应 · 错了 Tori 歪头重来

🔍

4. 语法小卡 (Grammar)

每天 0 或 1 个语法点 · 一句话讲清 + Tori 举例 · 不超过 90 秒 · 不堆术语

✍️

5. 输出练习 (Output)

三选一：① 默写核心句 ② 录音跟读 ③ 场景选择题。每天换花样不让用户疲劳

🌙

6. 日记收尾 (Recap)

Tori 总结今天 · 颁发"今日贴纸" · 预告明天 · 解锁短剧花絮（如果有）

7动效 / 声效 / 反馈系统

高级感不是堆功能，是每一个微交互都被打磨。用户感受到"这个产品有人在用心做"。

动效层级（4 档）

层级用例时长缓动
L1 · 反馈翻卡、按钮按下、tab 切换120msease-out
L2 · 转场页面切换、Sheet 上滑200–320mscubic-bezier(0.2,0.7,0.2,1)
L3 · 庆祝答对、解锁贴纸、完成 7 天800–1200msspring
L4 · 仪式Day 30 毕业、年付付费成功3–5 秒编排序列

声效系统（极简，宁可没有也不要烂的）

  • 翻卡 / 解锁：日记本翻页"沙沙"声 · 极轻 · 默认开
  • 答对："叮"一声 · 像收到消息的提示音 · 温暖不刺耳
  • 答错：完全静音 · 不惩罚 · 只用视觉反馈（Tori 歪头）
  • 胡萝卜解锁：低低的"咔哒"+ Tori "야호！"语音（真人录音）
  • 毕业典礼：仅一次 · 一小段定制配乐（10 秒）

所有声音可在设置里一键静音。默认状态：声效开 / 背景音乐关。

触觉（仅 PWA + 移动端）

  • 翻卡：navigator.vibrate(10) 微震
  • 答对：vibrate([10, 30, 10]) 双脉冲
  • 解锁胡萝卜：vibrate([20, 50, 20, 50, 40])

  • 年付 ¥128：相当于 ¥10.6/月，对比月付有 44% 折扣 — 用户会算账

  • 30 天免费：是钩子，不是亏本 — 完成 30 天的用户付费意愿是流失用户的 8–12 倍

12内容生产工作流

30 天 × 6 模块 = 180 个内容单元。这是工作量瓶颈。流程必须高效。

四步生产流程

  1. 剧本（你 / Claude 协助）：30 天的剧情大纲 · 每天的场景 · 每天的核心 5 句
  2. 语言（korean skill 写 + 你审）：每天 6 词 + 1 段对话 + 1 语法点的韩语撰写
  3. 音频（TTS 生成 + 你抽检）：sunhi 女声 · 全部句子预生成 mp3 上传 COS
  4. 组装（自动）：写到 src/data/diary/days.ts · 网页自动渲染

每天的内容字段（约定）

{
  day: 1,
  title: "抵达首尔",
  scene: "仁爪机场 → 出租车",
  diary: "今天到首尔了...",
  toriPose: "peek",
  clipUrl?: "/audio/diary/d1.mp4",  // 短剧切片
  words: [{ ko, zh, romaji, audio }, ...6],
  dialogue: { lines: [...], correctAnswers: [...] },
  grammar?: { rule, example, example_zh },
  output: { type: 'dictation'|'recording'|'choice', payload },
  recap: { toriSays, sticker, tomorrow_preview },
}

质量门

  • 每天剧本 → korean-qa skill 检查韩文自然度 · 조사 · 발음
  • 每周整体 → 重读一遍剧情连贯性 · Tori 语气一致性
  • 上线前 → 你亲自走完整 30 天
