# ScenePreview 内容审查规范 v1

## 触发条件

对 `src/data/scenePreview/{slug}.ts` 全部或部分场景进行内容质量审查。

---

## 审查者规则

1. **可以直接修改文件**——本次审查允许 Agent 使用 Edit / Write 工具修复问题
2. 修改前必须在报告里列出：原文 / 问题 / 修正后
3. 只改内容，不改数据结构（不删/新增字段，不改 emoji 除非明显错误）
4. 修改后必须跑 `npx tsc --noEmit` 确认类型无破坏

---

## 8 个字段全审

对每个场景文件，逐字段检查：

### ① sceneIntro（场景介绍）

| 字段 | 检查项 |
|---|---|
| headline | 15-25 字，有情绪/悬念，不是「场景是什么」而是「场景为什么有意思」 |
| lead | 40-80 字，1-2 句戳出场景本质，不重复 headline |
| facts[] | 3 个（不是 4 个！新规范）；每个 emoji + label（醒目数据）+ desc（8-24 字说明） |
| cards[] | 5 张；每张 60-120 字，讲文化现象 / 独特习惯 / 有趣故事，不是操作指南 |
| didyouknow[] | 3 条；q 15-25 字问题；a 40-100 字答案，含韩语术语 |

**质量红线**：
- 数据准确性：具体数字/年份/价格能不能查证？（如「1974 年 빙그레 设计」）
- 文化真实性：说韩国人「都喝冰美式」够真实吗？（얼죽아 是真的）
- 学生视角：一个初来乍到的留学生看得懂/感兴趣吗？

### ② openingHighlights

- 3 条「你会说」预览
- 每条 `{ role: 'user', ko, cn }`
- 必须从 patterns 或 vocab 里挑最经典的 3 句
- ko 语法必须正确，敬语层级要合（默认 요体）

### ③ culturalTips

- 2-3 条本地文化 tip
- 每条 `{ emoji, title 8-15 字, body 30-70 字 }`
- 内容不能跟 sceneIntro.cards 重复
- 侧重「行为准则」（做/不做什么），比 sceneIntro 更操作性

### ④ vocab（词汇）

对每个 PreviewVocabGroup：

| 字段 | 检查项 |
|---|---|
| title | 韩文·中文 双语标题，如「커피 종류 · 咖啡种类」 |
| items[] | 4-5 词/组，全场景总计 19-20 词 |

对每个 PreviewVocabItem：

| 字段 | 检查项 |
|---|---|
| ko | 韩语词汇，拼写正确，无 hidden hangul 错误 |
| cn | 中文翻译，1-6 字精简 |
| emoji | 一个 emoji（可选但建议有） |
| rom | 罗马音，用连字符分割（`a-me-ri-ka-no`） |
| example.ko | 完整韩语句，必须包含 ko 词汇本身 |
| example.cn | 中文翻译，跟 example.ko 对应（不多不少） |
| tip | 15-40 字使用/文化 tip，不是重复翻译 |

**韩语正确性检查**：
- 조사选择：은/는 · 이/가 · 을/를 · (으)로 前受体是否有받침
- 敬语层级：例句用 요체（-아/어요 / -이에요/예요），不用非敬语
- 拼写：外来语拼写要规范（카페 라떼 vs 카페 라떼）

### ⑤ patterns（句式）

对每个 PreviewPattern：

| 字段 | 检查项 |
|---|---|
| ko | 完整韩语句子（含标点） |
| cn | 中文翻译，与 ko 对应 |
| breakdown[] | 2-3 段拆解；role 用 主语/谓语/宾语/修饰（不能用「呼语」等其他） |
| breakdown 拼合 | 各段 text 拼起来能还原 ko 句 |
| tips[] | 2-3 条知识点：语法规则 / 量词助词 / 换词练习 |

### ⑥ responses（店员问你）

对每个 PreviewResponse：

| 字段 | 检查项 |
|---|---|
| npcKo | 店员问句韩语，用 요체敬语 |
| npcCn | 中文翻译 |
| userKo | 唯一正确回答（最地道版本） |
| userCn | 中文翻译 |
| correctNote | 20-40 字解释为什么这答案合适 |
| distractors[] | 3 个错误选项韩文，都是场景内常见短语但答非所问 |
| distractorNotes[] | 3 条解释一一对应 distractors |

**关键**：干扰项不能明显错，要「貌似合理但答非所问」。

### ⑦ chatTasks（对话任务）

对每个 ChatTask：

| 字段 | 检查项 |
|---|---|
| label | 中文任务名，如「点单」 |
| emoji | 一个 emoji |
| hint | 一句话说明「此刻要说什么」 |
| suggestions[] | 2-3 个韩语候选句 |

### ⑧ dialogues（完整对话）

对每个 PreviewDialogue：

| 字段 | 检查项 |
|---|---|
| title | 「对话 A · 简单点单」/「对话 B · 定制需求」 |
| lines[] | 5-10 行（A 长 6-9，B 短 4-6） |
| lines[].role | `npc` / `user` 交替（可微调） |
| lines[].ko | 完整韩语句 |
| lines[].cn | 中文翻译 |

**关键**：
- 对话流程真实（进店 → 点单 → 选项 → 结账）
- 敬语层级一致：店员用 요체（-요/-습니다）
- 数字真实（4,500원 咖啡合理价，不出现 45,000 원 咖啡）

## 韩语专项审查

### 조사速查表

| 助词对 | 受体末音 | 用哪个 |
|---|---|---|
| 은/는 | 有받침 → 은；无받침 → 는 |
| 이/가 | 有받침 → 이；无받침 → 가 |
| 을/를 | 有받침 → 을；无받침 → 를 |
| (으)로 | 有받침（ㄹ除外）→ 으로；无받침或ㄹ → 로 |
| (이)나 | 有받침 → 이나；无받침 → 나 |
| (으)면 | 有받침 → 으면；无받침 → 면 |

### 汉韩混排规则

以下字段禁止在同一文本节点内**同时**出现汉字和韩文：
- ko / userKo / npcKo / cardExamples.korean 等**纯韩语字段**
- cn / userCn / npcCn 等**纯中文字段**

允许：
- title / label / tip / note 等**说明性字段**——可混排（如 「N + 주세요」= 请给我 N）
- headline / lead / body 等**中文叙述字段**——可含韩文引用

### 敬语一致性

- 店员对客人：요체或 하십시오체
- 客人对店员：요체（不要用非敬语）
- 朋友之间：可用 반말（하다/해）
- 家人之间：随便

## 输出格式

审查完毕，输出：

```
# 场景 QA 报告 · Batch{N}

## 审查场景
- {slug1} / {slug2} / ...

## 修改列表
| # | 场景 | 字段 | 原文 | 问题 | 修正后 |
|---|------|------|------|------|--------|
| 1 | daiso | vocab[0].items[2].ko | "이거" | 拼写 OK 但 rom 缺连字符 | "i-geo" → 已修 |

## 每场景摘要
- {slug1}: FIXED (N 处) / PASS
- {slug2}: FIXED (N 处) / PASS

## 验证
- tsc 通过：✅ / ❌
- 修改前后字符数：{before} → {after}
```

---

## 目标质量标准（PASS）

- 韩语零语法错误
- 中文翻译准确到位
- sceneIntro 数据可查证（不编造）
- 文化描述真实（非刻板印象）
- 结构符合数量要求（sceneIntro.facts=3, cards=5, vocab 4 组×4-5 词等）
